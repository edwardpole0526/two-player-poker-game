# Two-Player Poker Game

This is a Python command-line poker game for two players. The game includes betting rounds, community cards, folding, checking, calling, raising and poker hand evaluation.

## Features

- Creates and shuffles a 52-card deck
- Deals two cards to each player
- Shows the flop, turn and river
- Tracks each player's money and the pot
- Allows players to bet, check, call, raise or fold
- Determines the winner using poker hand rankings

## Poker Hands Evaluated

The game can evaluate:

1. Straight flush
2. Four of a kind
3. Full house
4. Flush
5. Straight
6. Three of a kind
7. Two pair
8. Pair
9. High card

## How to Run

Download the file and run:

```bash
python poker_project.py
```

Then follow the prompts in the terminal.

I built this project to practice Python classes, lists, dictionaries, functions, conditionals, loops and game logic.
